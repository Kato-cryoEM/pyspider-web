CA R - Correspondence Analysis - Reconstitute images

(4/1/96)

PURPOSE

Reconstitute SPIDER image file series from sequential, unformatted, transposed file. Presently works for up to 100 images, each 64x64 in dimensions. WARNING WARNING WARNING WARNING WARNING WARNING' AN OLD ROUTINE THAT IS NOT SUPPORTED ANY MORE. BETTER USE THE 'CA S*' SERIES OF SPIDER COMMANDS INSTEAD.

USAGE

.OPERATION: CA R

.NO. OF IMAGES, MASK RADIUS: 46,10
[Enter number of images contained in the sequential file = number of columns in transposed matrix; and enter mask radius used to create the original sequential file.]

.FIRST FILE: REC005
[Enter the name of the first image to be reconstituted. The subsequent images will then be stored in REC006, REC007, etc.]

.ENTER DIMENSIONS (NSAM,NROW): 32,32
[Enter the dimensions of the image files to be reconstituted.]

.BACKGROUND CORRECTION: 1.5
[Enter constant to be subtracted from each image.]

.SEQUEN FILE: SEQ001
[Enter the name of the sequential file.]
