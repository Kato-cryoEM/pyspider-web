RM SUM3N - Radon Transform - Sum/average 2D Into 3D Fourier Radon transform

PURPOSE

Adds or subtracts a 2D Fourier Radon transform into or from a 3D Fourier Radon transform. The number of images added is recorded in the 3D transform in each line, so that multiple images from different direction, which represent different common lines can be averaged or subtracted with the correct weight.

SEE ALSO

RM 3DN [Radon Transform - 3D]
RM COMPLN [Radon Transform - 2D, Complete]

USAGE

.OPERATION: RM SUM3N

.+ OR - : +
[Enter + for addition of file 2 to file 1, - for subtraction of file 2 from file 1]

.(E)QUALIZED OF (P)OLAR SAMPLING: P
[Enter if the projections should be put into the 3D transform with equalized angular sampling (which will leave some lines empty, but may be needed for use in projection alignment) or polar sampling, which is the best for 3d Radon inversion.]

.(R)EAL OR (F)OURIER: R
[Enter if the imput is real or fourier. (cannot be seen from the file header.)]

.SET RESULT TO 0 WHEN SUM. INDEX IS 0 (Y/N): N
[If the line counter is 0 should the whole line be set to 0?]

.3D RADON FOURIER FILE: RADF001
[Enter name of first input Fourier-Radon or Radon transform. This file is overwritten.]

.SELECTION/ALIGNMENT INPUT DOCUMENT FILE OR *: CLASSALIDOC001
[Enter a document file with the key equal to the file number (gaps allowed) and the first column containing a value, either 0 and 1 for straight selection of e.g. a cross-corelation coefficient.]

If a file name was given the next questions and program output are:

minimum: xxxxx maximum: xxxxx average: xxxxx sigma: xxxxx
.REGISTER 1 THRESHOLD OR: 0,<SIGMA MULTIPLIER: 0.2 OR 0,-1.
[If a fixed value is given (in this example 0.2) then only those images with a value larger than 0.2 will be processed. If 0 and a sigma multiplier are given, then the program calculates: threshold=average*<sigma multiplier>*sigma and only processes images with a value larger than threshold.]

.NAME OF FIRST 2D FILE: RADON2D0001
[Enter the name of the first 2D Radon or Fourier Radon transform.]

If a * was answered to the document file question, then the following two questions will appear:

.FILE NAME TEMPLATE: RADF***
[Enter name emplate of 2D input Fouier-Radon transform. Projection angles need to be in the file header in position 1 (see ST)]

.FILE NUMBERS: 1-3000
[Enter file numbers of input files.]

.POSITION FOR READING ANGLES: 1
[Enter one of the 3 possible locations where the projection angles in the header of the 2D Radon Fourier transforms are kept. (s. ST)]

.SYMMETRY FACTOR IN PHI: 4
[Currently allows for symmetries only around the z-axis. If a symmetry factor of n is entered, the Fourier-Radon transforms are added in n symmetry related positions.]

.FILE NUMBERS RADOMIZATION WITH REPLACEMENT?(Y/N): N
[For statistical purposes it is possible to randomly pick a subset of images (can also be several identical)).

if Yes was answered:
.NUMBER OF DRAWS: 1500
[draw 1500 images from the set.]

Answer * if you do not want a document file:
.STATISTCS DOCFILE: STATDOC001
[This document file will contain the list of file numbers drawn.]
