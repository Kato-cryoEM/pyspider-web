CO S - COntour into STERECON storage files

(4/18/96)

PURPOSE

Reads SPIDER image file, extracts contours, and transfers contours into a SPIDER contour metafile.

USAGE

.OPERATION: CO S

.NEW CONTOUR FILE? (Y/N): Y
[Yes starts a new STERECON file for the reconstruction. No enters contours into an existing file. If the response is "Y" the following questions appear.]

.MAXIMUM NUMBER OF SECTIONS IN THE RECONSTRUCTION: 64
[Maximum number of sections the file can hold.]

.MAXIMUM NUMBER OF CONTOURS IN ANY SECTION: 20

.NUMBER OF CLASSES IN THE RECONSTRUCTION: 2

If there are multiple classes then you must give each class a four letter name. The system will list the class numbers and ask you to assign a class name for each class.

CLASS NUMBER = 1
.ENTER CLASS NAME (4 LETTERS): L157

CLASS NUMBER = 2
.ENTER CLASS NAME (4 LETTERS): L180

.ENTER TITLE (MAX. 40 CHARS): TITLE

For either old or new contour files the system now asks for the name of the contour file.

.ENTER CONTOUR FILE NAME: CNT001

.ENTER PREFIX OF IMAGE FILE NAMES: RIB

.ENTER FILE NUMBERS: 1-64

If the file has multiple classes you will be asked for the name of this class.

.ENTER CONTOUR CLASS NAME: L157
[If you want to have contours of different classes in the same reconstruction use the CO S operation multiple times with same output file.]

For the first file requested the system will list the maximum and minimum values in the image and ask for contouring info.

.STARTING CONTOUR LEVEL: 0.1
[Contours are drawn starting at this value.]

.ENDING CONTOUR LEVEL: 0.6

.CONTOUR LEVEL INCREMENT (>>ENDING FOR 1 CONTOUR): 0.1
[Separation between contour levels.]

.MIN LENGTH CONTOUR SAVED: 14
[Contours shorter than this will be discarded.]

All images contoured into the STERECON file on this "CO S" operation will be contoured at these levels. As each contour is transferred to the plot file the contour level and the length of the contour are listed.

NOTES

  1. To display the contours use STERECON system.

  2. To convert to Sterecon II use Stereocon, INT, OLD.

  3. To convert Sterecon II to Inventor format use ssrtoiv.

  4. Not Distributed!
