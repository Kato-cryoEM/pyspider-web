RM MAKE3 - Radon Transform - Create blank 3D Radon (or Polar Fourier) Transf.

(12/99)

PURPOSE

Creates an empty volume with the correct header and format for a 3D Radon Transform (or its Fourier Transform) (New format)

SEE ALSO

RM 2DN [Radon Transform - 2D]
RM 3DN [Radon Transform - 3D]
RM COMPLN [Radon Transform - 2D, Complete]
RM FTN [Radon Transform - Fourier transform]
RM FTINVN [Radon Transform - Inverse Fourier transform]
RM SUM3N [Radon Transform - Sum/average 2D Into 3D Fourier Radon transform]
RM INV2N [Radon Transform - Computes inverse (Fourier-)Radon transform]
RM INV3N [Radon Transform - Computes inverse 3D (Fourier-)Radon transform]

USAGE

.OPERATION: RM MAKE3

.OUTPUT FILE: EMPTYRADF001

.P-DIMENSION OF RADON TRANSF.: 80
[enter the p-dimension of the Radon transform. The dimensions of the created file are either 4 or 6 larger in x, because of additional data that are kept in each line of the new format Radon transform.]

.INCREMEN IN THETA,PHI: 2,2
[Selfexplanatory]

.(F)OURIER OR (R)EAL: R
[Selfexplanatory]
