CA M - Correspondence Analysis - Map

(7/1/85)

PURPOSE

Produces a correspondence anaylsis map on the terminal or in the results file by using the coordinates in the cluster file from a previous CORAN run.

USAGE

.OPERATION: CA M

.CLUSTR FILE: CLU002
[Enter the name of the cluster file from a previous CORAN run.]

.MAP#, NO. OF ELEMENTS IN MASK: 13,1530
[The two digits of the map code specify the factorial map you wish to print out. For example, the code '13' specifies a map of the first vs. the second eigenvector. Note that the digits must be in ascending order; '31' would be an invalid code. The highest digit specified must not exceed the number of factors specified in the CORAN control file. The number of points in mask refers to the masking done in the preparation of the sequential file by 'CA_E'. If no mask was applied ('CA'), use the total number of image elements printed out at the end of the CA run.]

.ENTER CENTER COOS: 0,-275
[Enter the coordinates of the point on which a circle is to be centered. Images falling within this circle will be listed out. If no circle is desired, hit <return> for this and the next response.]

.ENTER RADIUS: 150
[Enter the radius of the circle desired.]

NOTES

  1. The printout is very similar to the CORAN output map; however, the vertical axis always corresponds to the first factor in the map code. A number on the right margin gives the total number of images falling into the corresponding print line. This number will help you to identify overlaps of images on the map. Printed out at the top of the map is the following additional information: 1) The range of values in the two-factorial directions. The ranges are proportional to the eigenvalues, and reflect, on an absolute scale, the fraction of "energy" contained in the corresponding eigenvectors. 2) The coordinates of the center of gravity.

  2. The radius of the circle that you specify is most easily estimated from the min and max of each axis, which provide a rough guide to scale. The center of gravity coordinates (rounded to the nearest integer values) may provide a useful initial circle center. In batch, these values do not appear on the terminal and therefore cannot be used as guidelines.

  3. Not Distributed!
