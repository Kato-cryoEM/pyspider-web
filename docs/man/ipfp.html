IP FP - Interpolate - Using Fourier based bicubic polynomial ||

(06/02/11)

PURPOSE

Takes input image of any dimension and creates interpolated image of any dimension. Does not work on volumes.

SEE ALSO

IP [Interpolate - Bilinear]
IP T [Interpolate - Triangular]
DC [Decimate image/volume]

USAGE

.OPERATION: IP FP

.INPUT FILE: PIC001
[Enter name of file containing input image.]

.INTERPOLATED OUTPUT FILE: IMG022
[Enter name of file where output image is to be placed.]

.ENTER DIMENSIONS (NSAM, NROW): 72, 48
[Enter X & Y dimensions for the output image]

NOTES

  1. The output image does not have to have the same proportions (ratio NSAM/NROW) as the input image.

  2. The program works by throwing a new grid onto the image whose boundaries coincide with those of the old grid. Each pixel of the new grid is computed by Fourier based bicubic spline interpolation.

  3. This operation works for 2-D images only, not for volumes.

  4. Pixel size in header is updated.

  5. Implemented by: G. Kishchenko.

SUBROUTINES

INTERPS, INTERP_FBP
