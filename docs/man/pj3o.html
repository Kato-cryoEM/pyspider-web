PJ 3O - Project - 3D volume (older version)

(9/17/03)

PURPOSE

Computes a projection of a 3D density distribution according to three Eulerian angles. This older version has greater aliasing than the current operation

SEE ALSO

PJ 3 [Project - 3D volume]
PJ 3Q [Project - 3D volume using Eulerian angles ||]
PJ AT [Project - 3D volume using exponential Attenuation]
PJ CYL [Project - 3D volume onto Cylinder]

USAGE

.OPERATION: PJ 3

.INPUT FILE: PIC001
[Enter the name of the file whose projection is to be computed.]

.PROJECTION SAMPLE DIM.: 110, 78
[Enter the X dimension and (optional) Y dimension for the projection file. If the Y dimension = 0 then the Y dimension is chosen such that the X/Y ratio in the projection is the same as in the volume. Arbitrary dimensions can be used.]

.OUTPUT FILE: PRJ001
[Enter the name of the file where the projection is to be stored.]

.PHI, THETA: 45.5,27.2
[Enter the phi and theta angles, in degrees.]

.PSI: -30.0
[Enter the psi angle, in degrees.]

NOTES

  1. Warning. Projection through a volume containing both negative and positive numbers may not give the results you are expecting?

SUBROUTINES

PJ3
