CL CLAF - CLassification - Fuzzy

(11/7/88)

PURPOSE

Apply fuzzy partitioning techniques to the classification of images in factor space. Three techniques are currently available: Gustafson-Kessel (metric with a Mahalanobis distance), Roubens (non-metric Euclidian distance) and Fuzzy C-Means (metric Euclian distance). Either a classification in itself can be carried out or, instead, a cluster validation search can be performed (the cluster validation is implicitly making a classification, a choice of FZ and GK are available).

USAGE

.OPERATION: CL CLAF

.INPUT IMC-FILE CODE: 6
[Enter number of the IMC file previously created by CORAN85, which contains the image coordinates in factor space]

.INPUT CLUSTER-FILE CODE: 001
[The code of the cluster file where cluster and classification parameters are put for later reference. The file actually created will be called CLU001].

.FACTOR NUMBERS FOR CLUSTERING: 1-3,6-8
[Enter factors to be used in the cluster search]

.NUMBER OF CLUSTERS: 3,5
[If you are performing a classification the first number is the number of clusters into which the algorithm will partition the data, the second number will be ignored. If you are performing a cluster validation the two numbers indicate the interval along which the search will be conducted).

.WHICH METHOD? (GK, FZ, RB, CV...): FZ
[GK, FZ and RB are classification options, GK means Gustafson-Kessel, FZ means Fuzzy C-Means, and RB Roubens. CV is the option for cluster validation search]

.FUZZY EXPONENT (1,INF.), EPSILON TO STOP ITERATION: 1.3,0.01
[The fuzzy exponent is defined beteen 1.00001 and infinite. 1 would correspond to a totally hard classification and infinite to a maximally fuzzy classification. For most practical purposes 2 is a very fuzzy classification, and around 1.5 is an acceptible compromise hard/fuzzy. The algorithm will stop iterating when the changes in either the center of the clusters between succesive iterations were smaller than epsilon (for GK), or the pertenence function for any point changes less than epsilon. In general a value of 0.0001 (for GK) or 0.01 (for FZ and RB) is good.

IF the classifications options were selected

.MAXIMUM NUMBER OF ITERATIONS ANYWAY: 50
[Irrespective of the value of epsilon, this marks the total number of iterations].

.THRESHOLD FOR HARD-PARTITIONING TRANSFORMATION: 0.6
[This parameter establishes a threshold that is applied only in the print-out of the program. It is just intended to be a help in studying the results. This value is not used at all during the fuzzy classification. Images will be considered "safely" classified when their pertenence to a given cluster were larger than this threshold. Clusters will be marked from 1 to N (N of clusters). An additional cluster, cluster 0, is formed with the images that have a pertenence function below the thershold. If either GK or FZ was selected, this assignement is used by all other programs handling this file; however, if RB was selected, the hard assignement provided by the Roubens method itself is the one that is carried on].

If "FZ" was selected:

.INPUT INITIAL POINTS? (Y/N):? Y
[It allows to choose the center of the clusters for the first iteration. If answered "Y" it asks:

CLUSTER NUMBER 1

.CORRESPONDING CLUSTER CENTER (IMAGE): 234
[Where "CLUSTER NUMBER" shows the current cluster for which a given image is being selected as initial cluster center. In this way local minima can be studied and/or the global convergence can be speeded-up. The actual number to be entered is the image identifier number (as it appears in a factor map)].

IF the cluster-validation option was selected:

.MAXIMUM NUMBER OF ITERATIONS ANYWAY:
[Irrespective of the value of epsilon, the maximum number of iterations marks the stop of the iterative classification process.]

.NUMBER OF BOOTSTRAPS, NUMBER OF INITIALIZATIONS: 100,40
[The cluster validation techniques have been based on the ideas of Moreau and Jain (see reference below). They perform a number of bootstraps (sampling with replacement) and a number of initializations in order to impruve the consistency of the data. Attention: The number of searchs will be the products of the N bootstraps X N initializations!!!. This number is usally large and thus the computation is very long].

.METHOD TO BE USED (0=FCM, 1=G-K):
[If 0 is selected the classifications will be carried out by the Fuzzy C-Means approach. If 1 is selected the Gustarfson-Kessel method will me used].

NOTES

  1. If the classifications options were selected:
    The results will be stored in the cluster file. Besides that, the Results file will also have all the information. The first part of the Results file is an echo of the parameters used in the classification. The membership matrix follows. The information provided here is "element" (element identifier), "pertenence" (pertenence function to each cluster), "decission" (cluster assignement based on the threshold used), and "max.pertenence" (it shows which was the maximum pertenece function that the element had). At the end, the cluster centers, the total number of element per cluster, the listing of the images in each class, and the total number of iterations are shown. IF RB was selected, the print-out of the membership matrix will consist of "element, "Roubens hard classification", "pertence", "decission", "max.pertenence".

  2. If the cluster validation option was specified
    The Results file will include a heading echoing the selection of input options and a listing of a number of relevant cluster validity criteria. Up to the present experience, the best of them is the one proposed by Moreau and Jain (1986).

  3. References:
    For GK and FN: James C. Bezdek, Pattern Recognition with fuzzy objective function algorithms, Plenum Press, New York 1981.
    For RB: Marc Roubens, European Journal of Operational Research (1982), 10: 294-301.
    For cluster: All the above ones plus Moreau, J.V. and Jain, A.K. validity (1986), IEEE Int. Conf. on Compt. Vis. and Patt. Rec., pp. 634-636.

  4. Not distributed!!
