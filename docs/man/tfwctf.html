TF WCTF - Transfer Function - 3D CTF correction

(05/10/02)

PURPOSE

3D CTF correction of volume series by Wiener filtering using freqeuncy dependent SSNR.

SEE ALSO

TF CTS [Transfer Function - 2D & 3D CTF correction]

USAGE

.OPERATION: TF WCTF

.ENTER TEMPLATE FOR IMAGE FILE: img***
[Enter template name of a volume series to be restored.]

.ENTER FILE NUMBERS OR SELECTION DOC. FILE NAME: 1-10
[Enter file numbers. The file numbers can also be read from a selection document file where file numbers are contained in the first register (not the keys).]

.ENTER TEMPLATE FOR CTF FILE: ctf***
[Enter template name of file series containing CTFs for respective images. The CTF files have to have the same number as corresponding defocus groups.]

.ENTER SNR TEMPLATE : snr***
[Enter template name of Signal-to-Noise Ratio document files.]

.OUTPUT FILE: MOL003
[Enter name for 3D output file.]

NOTES

  1. Input files can be either real or Fourier format. CTF files must be in Fourier format. All files must have the same dimensions. Output file is real.

  2. CTF functions can be generated 'TF C3'. All parameters have be determined using 'TF ECTF' and 'TF ACTF'.

  3. Implemented by L. JOYEUX.

SUBROUTINES

WCTF

CALLER

UTIL1 
EXAMPLE: 3D reconstruction process, CTF correction part

      ; create SSNR functions form FSC 
      do lb99 x99=1,x66
         sn rb,x20,x21
         refinement/defgrp{***x99}/dres{***x86}
         l

         sn rf
         x20,x21
         (37)
         (0.1,0.98)
         (2)
         refinement/snr{**x76}_{***x99}

      lb99

      ; ctf correction using snr (function of fsc)
      tf wctf
      refinement/defgrp***/ttvol{***x86}
      1-x66
      refinement/ctf***
      refinement/snr{**x76}_***
      (0.5)
      (1)
      refinement/tvol{***x86}
