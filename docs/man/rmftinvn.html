RM FTINVN - Radon Transform - Inverse Fourier transform

PURPOSE

Computes the inverse Fourier Transform of a 2D or 3D Radon Transform. 2D and 3D, mixed radix, new format.

SEE ALSO

RM 3DN [Radon Transform - 3D]
RM COMPLN [Radon Transform - 2D, Complete]
RM FTN [Radon Transform - Fourier transform]

USAGE

.OPERATION: RM FTINVN

.RADON FOURIER INPUT FILE: FRAD001
[Enter name of Fourier space Radon transform.]

.X-DIMENSION OF OUTPUT (DEF=NX-2): 128
[Enter the x-dimension of the output file, needs to be at least 2 pixels smaller than the x-dimension of the Fourier transform.]

.RADON OUTPUT FILE: RAD001
[Enter name for real space Radon transform.]

NOTES

SUBROUTINES

FOURADINVCN, FOURADINVN, MRFOUR1
