OR AM - ORientation search - 2D, check mirror ||

(02/05/03)

PURPOSE

Determines rotational and trasnlational orientation between two images using self-correlation functions with additional check of mirror transformation.

SEE ALSO

OR A [ORientation search - 2D ||]

USAGE

.OPERATION: OR AM,X21,X22,X23,X24,X25

[The optional output registers contain: X21 - rotation angle, X22,X23 - X- and Y- shifts, X24 is 0 when there is no mirror, and 1 when there is mirror operation necessary, X25 - not-normalized correlation coefficient.]

.INPUT FILE: UUU001
[Enter name of the file.]

.REFERENCE FILE: GGG002
[Enter the name of the file containing the reference picture; dimensions must correspond to those of the first picture.]

.Real space mask radius for the input and reference images: 25,15
[The radii applied in real space to the input and reference images, respectively.]

.RADIUS OF THE ACF, MAXIMUM SHIFT: 20,5
[Enter the maximum radius of the self-correlation function to be used in angle determination and the maximum shift to be considered.]

NOTES

  1. This command employs the same method as AP NQ. For details see:
    Joyeux, L. and P.A. Penczek. Efficiency of 2D alignment methods. Ultramicroscopy, 92, 33-46 (2002).

  2. Implemented by: Paul Penczek
