VO CEUL - Vector Operation - Combine Euler rotations

(08/16/96)

PURPOSE

Combines two sets of three Euler angles into a single set of three Euler angles. The definition of the Euler rotations is as follows: 
r' = D(psi) D(theta) D(phi) r
with:
| cos(psi) sin(psi) 0 |
D(psi)=|-sin(psi) cos(psi) 0 |
| 0 0 1 |
| cos(theta) 0 -sin(theta) |
D(theta)=| 0 1 0 |
| sin(theta) 0 cos(theta) |
| cos(psi) sin(psi) 0 |
D(psi)=|-sin(psi) cos(psi) 0 |
| 0 0 1 |
These definitions are consistent with the angle definitions used in 'BP GWE' (General Weighting using three Euler angles) and 'BP 3E'(Simple BackProjection using 3 Euler angles).
The program originally was written for a multicone 3D reconstruction. Thus, the angle found in the header from a standard two-dimensional alignment of the 0 deg images in a tilt pair corresponds to the second Euler rotation. Note that the first rotation of the object or specimen occurred when it was applied to the microscope grid.

WARNING

This program has never been extensively used in all its permutations. So, be sure to check that the angles you get are the correct ones. (The combination of Euler rotations is correct; however, the order of angles as they are picked from the file title or out of the document file might differ from the description.)

USAGE

.OPERATION: VO CEUL X11,X12,X13
[register only used in option E]

.(H)eader, (D)oc.file, (E)xternal, (M)ixed=H+E:
[Option H: if two sets of three input angles are to be read from the file header and the result be stored back into the header. There are three positions for Euler angles:
Position 1 is at buffer location 15,16,17 = final position
Position 2 is at buffer location 31,32,33
Position 3 is at buffer location 34,35,36 = saved position

If location 3 is empty, the program uses the angles in position 1 as the second Euler rotation, combines them with the angles in position 2 as the first Euler rotation, and stores the result back into position 1. The angles originally found in position 1 are saved in position 3.

If location 3 is not empty, the program uses the angles in position 3 as the second Euler rotation, combines them with the angles in position 2 as the first Euler rotation, and stores the result into position 1. The angles originally found in position 3 remain there.

.ENTER 3 LETTER FILE PREFIX OR TEMPLATE (EG. PIC***): PIC***

.ENTER FILE NUMBERS: 1-2000
[Maximum number of files is 2000 (can easily be changed)]

Option D uses document files as input and output:

.input document$ FILE: DDD001
[The input document file must contain the following columns:

key 6 phi2 theta2 psi2 phi1 theta1 psi1 ]

.first,last key: 27,133
[enter first and last that should be used]

.output document$ FILE: DDD002
[enter name of output document file. This file will have the format:

key 3 phi theta psi ]

Option E allows external entry of angles:

.phi1,theta1: 10,20

.psi1: 30
[Enter angles of first Euler rotation]

.phi2,theta2: 40,50

.psi2: 60
[Enter angles of second Euler rotation]

The result of option E will be found in the [optional] registers in the operation line.

Option M is for mixed input/output:
adds a second rotation to the rotation in the file headers of a series of files.

.ENTER 3 LETTER FILE PREFIX OR TEMPLATE (EG. PIC****): PIC***

.ENTER FILE NUMBERS: 37-1867

.second set of angles in (F)inal or (S)aved position: F
[Answer F if the angles of the second Euler rotation are to be taken from position 1. The combined angles will be stored again in position 1 and the original second rotation saved in header position 3. Answer S if the second rotation had already been saved there, e.g., if the calculation is repeated with a different second rotation.]

.phi1,theta1: 10,-176

.psi1: 358
[Enter the three Euler angles of the first rotation]

NOTES

  1. This program should be used with caution (for the time being), until it is assured that everything works properly. Especially, check that the rotations were not interchanged. Use the operation FI to check that all file headers have been updated correctly.

  2. Not distributed!
