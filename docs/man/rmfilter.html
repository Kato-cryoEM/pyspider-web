RM FILTER - Radon Transform - Filter

(11/1/2000)

PURPOSE

Applies the nontomgraphic noise reduction filter to a three-dimensional Radon transform ("new format"). This program is designed as part of the three-dimensional reconstruction algorithm by inversion of the 3D radon transform created with "RM SUM3N" from a series of 2D Radon transforms (RM 2DN).

SEE ALSO

RM 2DN [Radon Transform - 2D]
RM 3DN [Radon Transform - 3D]

RM SUM3N [Radon Transform - Sum/average 2D Into 3D Fourier Radon transform]
RM FTN [Radon Transform - Fourier transform]
RM FTINVN [Radon Transform - Inverse Fourier transform]
RM INV3N [Radon Transform - Computes inverse 3D (Fourier-)Radon transform]
RM INV2N [Radon Transform - Computes inverse (Fourier-)Radon transform]

USAGE

.OPERATION: RM FILTER

.3D RADON INPUT FILE: 3DRAD001
[Enter the name of the three-dimensional Radon transform that you want to filter.]

.3D RADON OUTPUT FILE: 3DRADOUT001
[Enter the name for the filtered 3D Radon transform.]

.DATA SLICE FOURIER OUTPUT FILE: DATAF001 OR *
[Enter a file name for the Fourier transform of one slice of the input data (the first one). Enter * if you do not want it. This and the following option are intended for observing and testing the behaviour of the filtration.]

.MASK OUTPUT SLICE FILE: MASKSLICE001 OR *
[Enter a name for the first slice of the filtration mask. Enter * if not wanted.]

.RADIUS OF RADON TRANSFORM MASK: 21
[Enter the radius of the mask that was used in "rm 2dn". If you want to filter less, then use a larger radius.]

the program writes: there are several versions possible: 1 = filter in z-slices only, no iterations 2 = filter in y-slices only, no iterations 3 = filter first z then y, no iterations 4 = filter first y then z, no iterations 5 = pocs z-slices only 6 = pocs y-slices only 7 = pocs first z then y-slices 8 = replace only, y and z slices, no iterations

.MODE, # OF ITERATIONS: 5,10
[Enter what you want to do. In 1-4 the portion of the 2D Fourier transform of each slice, that according to the theory of sinogram transforms should be 0, is set to 0. In the higher modes, the program checks which of the lines in the 3D Radontransform contain data and replaces these lines after filtration with the original data (see fuzzy pocs, below). The combination of filtration and replacement results in a version of POCS where the two projectors are 1) Radon transform consistency, 2) replacement.) POCS works only if the 3D transform was created with "RM SUM3N"

if an option with replacement was chosen, the program asks:
.REPLACEMENT FACTOR F, 1 HARD POCS, 0<F<1 FUZZY POCS: 0.5
[Enter a value less than 1 if you want fuzzy pocs. In this case the "replacement formula is (filtered data)(1-f)+f(original data).

NOTES

  1. Attention: THESE PROGRAMS WORK CORRECT ONLY WITH THE NEW FORMAT OF THE RADON TRANSFORM. THERE IS NO ERROR CHECKING (POSSIBLE) FOR THE CORRECT FORMAT. (Each line is 4 pixels longer than the p-dimension of the transform or 6 pixels longer when Fourier transformed. In the old format a line in the real space Radon transform had p pixels and its Fourier transform p+2 pixels.)

  2. For details of the theory see: Lanzavecchia S., Bellon P.L., Radermacher M., Fast and Accurate Three-Dimensional Reconstruction from Projections with Random Orientations via Radon Transforms. J.Struct.Biol. 128,152-164, 1999

  3. Author: M.Radermacher

  4. AT this time the alignment programs have not been rewritten yet for the "new format").
