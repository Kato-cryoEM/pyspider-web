HI DOC - HIstogram of a column in a document file

(2/09/04)

PURPOSE

Computes a histogram of one column of a document file and puts the histogram in a user specified document file.

SEE ALSO

HI [HIstogram - output in results file]
HI R [HIstogram - output in results file, specified range.]
HI T [HIstogram - output on Terminal]
HI TR [HIstogram - output on Terminal, specified range]
HI DR [HIstogram - output in Document file, specified Range]
HI M [HIstogram - masked area]

USAGE

.OPERATION: HI DOC

.INPUT FILE: defocus1
[Enter the name of the document file to be histrogramed.]

.COLUMN FOR HISTOGRAM: 1
[Enter the number of column to be calculated .]

.NUMBER OF BINS: 20
[Enter the number of bins to be set.]

.DOCUMENT FILE: DOC001
[Enter name of output document file]

SUBROUTINES

HI_1D
