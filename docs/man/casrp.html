CA SRP - Correspondence Analysis - PCA reconstitution

(10/12/03)

PURPOSE

Reconstitute complete images using PCA reconstitution.

SEE ALSO

CA S [Correspondence Analysis - Solution]
CA SM [Correspondence Analysis - Show Map & Eigen Values]
CA SR [Correspondence Analysis - Reconstitute images]
CA SRD [Correspondence Analysis - Reconstitute Differential images]
CA SRI [Correspondence Analysis - Reconstitute Importance images]
CA VIS [Correspondence Analysis - Create VISual map]

USAGE

.OPERATION: CA SRP

.CORAN/PCA FILE PREFIX: pca_t_
[Enter the prefix for the files created in 'CA S'.]

.ENTER FILE NUMBERS TO BE USED (EG. 1-8,12-22,55): 1-80,90-95
[Numbers are consecutive, and refer to the sequence of files specified in 'CA S'. ]

.MASK FILE: *
[Enter the name of the mask file specified in 'CA S' or '*' if none.]

.SUBTRACT AVERAGE IN PCA RECONSTRUCTION? (N/Y): N

.ENTER FACTORS TO BE USED: 2-4
[Enter the factors to be used for image reconstitution. note that the numbers have to be less that the number of images and less or equal to the number used in 'CA S'.]

[If there is no image with the above given number, then coordinates are solicited for each of the factors specified]

.ENTER COORDINATES FOR EACH FACTOR SELECTED: 0.0013, -0.0011,
0.0004

NOTES

  1. The purpose of this operation is threefold:

  2. To reconstitute approximation of original images using chosen factors: use file numbers of the original images in "ENTER FILE NUMBERS";

  3. To create eigenimages - images corresponding to chosen eigenvectors: use file number (one) non-existing in the original image series in "ENTER FILE NUMBERS", answer Yes in "SUBTRACT AVERAGE IN PCA RECONSTRUCTION", use only one (chosen) factor number in "ENTER FACTORS TO BE USED", and answer 1.0 in "ENTER COORDINATES FOR EACH FACTOR SELECTED" (or -1.0, since the sign of eigenvector is not determined by the analysis);

  4. To create non-existing images using chosen factors and arbitrary coordinates: use file numbers non-existing in the original image series in "ENTER FILE NUMBERS", answer No in "SUBTRACT AVERAGE IN PCA RECONSTRUCTION", enter (arbitrary) factor coordinates in "ENTER COORDINATES FOR EACH FACTOR SELECTED".

SUBROUTINES

JPMSK2, PCA_SRIP2, PCA_RECDUM, PCA_REMAKE
