LI R - LIst Registers - in results file

(10/7/99)

PURPOSE

To list contents of the SPIDER registers in the RESULTS file.

SEE ALSO

LI RD [LIst Registers - in Document file]
LI RT [List Registers - on Terminal]

USAGE

.OPERATION: LI R

[Registers are listed from X0 to X102. The system registers X0 ... X9 are listed separately . Their meaning is: 

 
          X0    DO-Loop index of the current loop                    
          X1    NSAM = number of samples of the last image accessed                                          
          X2    NROW = number of rows of that image                   
          X3    FMAX = its maximum pixel value                        
          X4    FMIN = its minimum pixel value                        
          X5    AV   = its average value                              
          X6    SIG  = its standard deviation                         
          X9    ERRFL = error flag

NOTES

  1. This operation is useful for debugging SPIDER procedures as it allows the transfer of registers to be monitored.
