SD SHUFFLE - Shuffle Document file

(5/95 M.R.)

PURPOSE

randomly shuffles a document file

SEE ALSO

SD [Save Document]
SD C [Save Document - from CA S (_IMC) file]

USAGE

.OPERATION: SD SHUFFLE

.SOURCE DOCUMENT FILE: DOC001
[Enter name of input document file]

.FIRST, LAST KEY NUMBER: 1,124
[Enter first and last key you want to use]

The output docfile will have the format:
newkey, 4, oldkey, + 3 columns

.INPUT FOR OUTPUT COLUMN 2: 3
[Enter input column number that will be stored in output column number 2]

.INPUT COLUMN # FOR COL.3,COL.4: 3,3
[Enter the column numbers of the values that will be kept in column 3 and column 4 of the output document file. these numbers may be all the same, in which case the entered input column value is simply repeated several times.]

.DOCUMENT FILE: DOC002
[Enter name of output document file]

SUBROUTINES

SHUFFLEDOC, SAVD, OPENDOC, UNSDAL

CALLER

DRIV3
