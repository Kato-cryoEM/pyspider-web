PDB RT3 - PDB - Rotates PDB file in 3D space

(9/16/06)

PURPOSE

Rotate PDB file by three Euler angles.

USAGE

.OPERATION: PDB RT3

.INPUT FILE: aaa.pdb
[Enter the name of the PDB file to be rotated with extension.]

.OUTPUT FILE: bbb.pdb
[Enter the name of the output PDB file with extension.]

.PHI, THETA, PSI: 100, 200, 300
[Enter three rotation angles in degree.]

NOTES

  1. The operation does not change the format of PDB file.

  2. Implemented by Zhong Huang, Pawel A. Penczek.

SUBROUTINES

PDBRT3

CALLER

PDB
