CA EIGPCT - Correspondence Analysis - Create Eigenvalue percent doc file

(2/1/13)

PURPOSE

Create document file containing eigenvalues from Coran or PCA analysis and the percentage of variance accounted for by each factor. See: Classification and Clustering Tutorial for further info.

SEE ALSO

CA S [Correspondence Analysis - Solution]
SD C [Save Document - from CA S (_IMC) file]

USAGE

.OPERATION: CA EIGPCT

.CORAN/PCA FILE PREFIX: cas_ca
[Enter the prefix identifying the data files created from a previous 'CA S' run: _IMC, _PIX, & _EIG. Do not include trailing underscore.]

.EIGENVALUE DOC FILE: cas_ca_eigpct
[Enter name of the document file that recives eigenvalues and percentages.]
