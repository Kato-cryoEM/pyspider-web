SD NLM - Save Document - from NonLinear Mapping

(3/22/96)

PURPOSE

Transfer image coordinates from 2D coordinate file resulting from nonlinear mapping (before Aug. 7th '93) to a standard SPIDER document file. (NOTE: Since Aug. 7 1993 the 2D file from nonlinear mapping is already in document file format and this conversion is not needed anymore.) This command is thus never needed on Unix SPIDER.

SEE ALSO

SD [Save document]
SDC [Save document - from cluster file]
SDS [Sort document file according to column]
SD SHUFFLE [Shuffle document file]

USAGE

.OPERATION: SD NLM

.2D FILE: TWOD001
[Enter name of 2D coordinate file from nonlinear mapping.]

.DOCUMENT FILE: NLMDOC001
[Enter name of output document file.]

SUBROUTINES

NLMCONV, SAVDN1

CALLER

DRIV3
