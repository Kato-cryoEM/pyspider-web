TF ACTF - Astigmatism estimation

(5/10/02)

PURPOSE

: Estimation of the astigmatism

SEE ALSO

USAGE

.OPERATION: TF ACTF,X10,X11,X12
[On output, X10,X11,X12 contain the defocus, the astigmatism amplitude and the astigmatism orientation.]

.INPUT IMAGE: pw_avg001
[Enter the power spectrum image (intensities, as produced by PW 2).]

.BACKGROUND & ENVELOPE DOCUMENT FILE: ctf001
[Enter a document file name that contains both the background noise and the envelope function, as produced by TF ECTF.]

.COLUMN NUMBER WHERE IS BACKGOUND: 3
[Enter the background column.]

.COLUMN NUMBER WHERE IS ENVELOPE: 4
[Enter the envelope column]

.PIXEL SIZE [A], SPHERICAL ABBERATION CS [MM]: 2.8,2

.WAVELENGTH LAMBDA(ANGSTROEMS)[A]: 0.037

.AMPL. CONTRAST RATIO [0-1]: 0.1

.DEFOCUS: 10000
[Enter the initial defocus value.]

.INTERMEDIATE OUTPUT IMAGE (ORIGINAL-BACKGROUND): out1
[Only for control purpose.]

.OUTPUT ESTIMATED CTF: out
[Create a power spectrum using estimated defocus, astigmatism and envelope.]

NOTES

  1. If astigmatism is present,the X10 will contain a corrected defocus value.

  2. The background and the envelope are estimated using TF ECTF.

  3. Implemented by L. JOYEUX

  4. TO DO: Fix the dependency of defocus versus astigmatism (check with TF C). There might be a sign inversion of the astigmatism amplitude.

SUBROUTINES

ACTF, GETDEFOCUS

UTIL1
