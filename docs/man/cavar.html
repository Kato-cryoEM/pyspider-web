CA VAR - Correspondence Analysis - Variance

(8/8/85)

PURPOSE

Calculates the variance and euclidean distance of an image in an image set relative to a reference image (a precalculated average). It produces as output a document file of the format: key, variance, interval #, Euclidean distance, interval # The key corresponds to the image #. Additionally a list is produced of the classes and their cardinal numbers, and the cardinal numbers of the sum of the accumulated classes.

USAGE

.OPERATION: CA VAR

.MASK FILE: MSK001
[Enter the name of a mask file. Only pixels inside the mask are used for the analysis.]

.AVERAGE FILE: AVG001
[Enter name of image relative to which the variances and Euclidean distances are calculated]

.FIRST FILE: IMA001

.LAST FILE: IMA999
[Enter names of first and last file in the image series. Gaps in the images numbers are allowed]

.CLASSIFICATION INTERVALS IN % : 5
[Enter the interval size to be used for classification in % of the maximum variance or Euclidean distance]

.DOC FILE: DOC001
[Enter the name of the document file]
