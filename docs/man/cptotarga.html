CP TO TARGA - CoPy SPIDER file to Targa format

(7/17/96)

PURPOSE

Copy SPIDER data file to a Targa format file. Only available on SGI Unix.

USAGE

.OPERATION: CP TO TARGA

.ENTER UNIX SPIDER INPUT FILE: SPI000
[Enter the name of the image to be converted.]

.ENTER TARGA OUTPUT FILE: TAR000
[Enter name for Targa image file.]

NOTES

  1. Routine is slow because it calls SGI image library routines which need a delay set to ensure completion of subprocesses.

  2. Implemented by: ArDean Leith
