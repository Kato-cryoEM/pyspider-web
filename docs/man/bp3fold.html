BP 3F OLD - Older Back Projection - 3D, Interpolated in Fourier space ||

(6/08/08)

PURPOSE

Calculates 3D reconstruction using interpolation in Fourier space. This operation is an older version of 'BP 3F'.

SEE ALSO

BP 3F [Back Projection - 3D, Interpolated in Fourier space ||*]
BP 32F [Back Projection - 3D, Sampled, Interpolated in Fourier space ||*]
BP 32F OLD [Older Back Projection - 3D, Sampled, interpolated in Fourier space ||]
BP CG [Back Projection - 3D, Iterative, Conjugate Gradients ||*]

USAGE

.OPERATION: BP 3F OLD

.ENTER TEMPLATE FOR 2-D IMAGE FILE: PROJ***
[Enter template for input projections.]

.ENTER FILE NUMBERS OR SELECTION DOC. FILE NAME: 1-700 OR IMAGES127
[Enter projection file numbers or the name of the document file containing projection file numbers in the first register.]

.ANGLES DOC FILE: ANGLES27
[Enter name of document file containing Eulerian angles for the projections used (psi, theta, phi).]

.SYMMETRIES DOC FILE: symmetries
[Enter the name of the document file containing Eulerian angles defining symmetries (psi, theta, phi). The angles should be such that when used in operation 'RT 3D' transform the volume into itself. The identity operation (angles 0,0,0) MUST be included.
The symmetries are enforced in two steps: projections related by the symmetry operations are added in Fourier space to the volume; in order to reduce the residual artifacts, additional real-space symmetrization is applied.
If there are no symmetries, enter symbol "*".]

.RECONSTRUCTED 3-D FILE: VOLUME1001
[Name of the output file.]

NOTES

  1. 5x5x5 Keiser-Bessel interpolation scheme is used.

  2. The projections do not have to have power-of-2 dimensions.

  3. Implemented by Paul Penczek.
