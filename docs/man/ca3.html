CA 3 - Correspondence Analysis - create 3-D volume

(7/1/85)

PURPOSE

Create 3-D volume and insert points according to 3-D image coordinates in a 3-D factorial axes coordinate system. These coordinates are found in the cluster file produced by CORAN. The symbols coding the images must end with the character '*'. (i.e., if there are more than 99 images, the images must be named 100*, 101*, etc., rather than *100, *101, etc.)

USAGE

.OPERATION: CA 3

.CLUSTER FILE: CLU001
[Enter the name of the cluster file from a previous CORAN run.]

.THREED FILE: THD001
[Enter the name of the three-dimensional output file.]

.ENTER NSAM, NROW: 32,32
[Enter the dimensions in x and y directions corresponding to the first and second factor axes, respectively.]

.ENTER NSLICE: 32
[Enter the dimension in z direction corresponding to the third factor axis.]

NOTES

  1. Original scaling between the three axes is maintained irrespective of the volume dimensions.

  2. Not Distributed!

SUBROUTINES

CA3D
