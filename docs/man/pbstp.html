PDB STP - PDB - Create PDB file from coordinate list

(9/16/06)

PURPOSE

Convert list of coordinates given in a SPIDER document file into a PDB file.

USAGE

.OPERATION: PDB STP

.INPUT FILE: spidoct
[Enter the name of the SPIDER document file.]

.OUTPUT FILE: abc.pdb
[Enter the name of the output PDB file with extension.]

NOTES

  1. The operation yields standard format PDB file with terminal atoms.

  2. Implemented by Zhong Huang, Pawel A. Penczek.

SUBROUTINES

PDBSTP

CALLER

PDB
