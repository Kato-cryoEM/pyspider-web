OR 2 - ORientation search - 2D, rotation, uses polar coords ||

(6/04/08)

PURPOSE

Determines rotational orientation between two images using resampling into polar coordinates. This is the same as: 'AP REF' or 'AP SH' without the translational search and it only acts on a single pair of images. (See align_overview.html for comparison of 'AP' and 'OR' operations.)
OBSOLETE! USE 'OR R' INSTEAD!

SEE ALSO

OR R [ORientation search - 2D, rotation, uses polar coords. ||]
AP SH [Alignment - multi-reference, exhaustive rotation & shift ||*]
AP REF [Alignment - multi-reference, rotation & shift ||*]

USAGE

.OPERATION: OR 2 [ang],[peak]

[The optional output parameters [ang],[peak] specify register variables to receive the rotation angle and the value of the angular correlation peak found in this operation.]

.INPUT FILE: UUU001
[Enter name of the image file.]

.REFERENCE FILE: GGG002
[Enter the name of the file containing the reference image. Dimensions must correspond to those of the input image.]

.FIRST, LAST RING, & RING STEP: 5,15,1
[Only rings with the radii in the range 5-15 (in pixel units) will be used. If skip=0 or 1 then each ring between 5 and 15 will be taken; for skip=2 every second, and so on.]

.(F)ULL OR (H)ALF CIRCLE: F
[F - full ring (360 degrees) will be used;
H - half ring (180 degrees) will be used.
Option 'H' is appropriate for rotational search using autocorrelation functions.]
