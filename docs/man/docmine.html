DOC MINE - Create Mineset files from Document files

(6/7/01)

PURPOSE

Creates Mineset input files from SPIDER document files.

SEE ALSO

SD C [Save Document - from CA S (_IMC) file]

USAGE

.OPERATION: DOC MINE

.INPUT DOCUMENT FILE: DOC002
[Enter name of SPIDER output document file.]

.MINESET OUTPUT FILE: mineset
[Enter name of Mineset output file. The data will be placed in a file with this name and extension: data. Another Mineset "schema" file will be created with the same basename and the extension "schema".]

SUBROUTINES

DOCS1, OPENDOC, LUNDOC

CALLER

DRIV1
