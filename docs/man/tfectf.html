TF ECTF - CTF Estimation

(5/10/02)

PURPOSE

Estimation of the CTF

USAGE

.OPERATION: TF ECTF,X10
[X10 is the defocus output value]

.PIXEL SIZE [A], SPHERICAL ABBERATION CS [MM]: 2.8,2

.WAVELENGTH LAMBDA(ANGSTROEMS)[A]: 0.037

.AMPL. CONTRAST RATIO [0-1]: 0.1

.POWER SPECTRUM DOC: roo001

.DOCUMENT FILE: ctf001

NOTES

  1. the output document file contains different columns:
    1 - power spectrum without background noise,
    2 - (CTF(f).envelope(f))**2,
    3 - squared background noise,
    4 - squared envelope function,
    5 - CTF(f).envelope(f).

  2. Power spectrum model is:
    pw(f) = ( CTF(f).env(f)(signal(f)+noise(f)) )**2
    + background noise (f)**2

  3. The output document file is used in "TF ACTF" command for the background, envelope and astigmatism estimation.

  4. Implemented by L. JOYEUX.
