CA - Correspondence Analysis - prepare sequential file

(7/1/85)

PURPOSE

Create a sequential unformatted file representing a series of aligned images in transposed form. Presently works for up to 400 images of 99x99. The file is used as input to CORAN. (For the new CORAN85, see 'CA S' options.)

USAGE

.OPERATION: CA

.FIRST FILE: SER001
[Enter the name of the first file in the series.]

.LAST FILE: SER050
[Enter the name of the last file in the series.]

.ENTER OFFSET,MASK RADIUS: 4,20
[Enter the number of files already in the sequential file, if you are appending to an existing file. If new, enter '0'. Additionally, enter the radius of a circular, centrally positioned mask you wish to apply to the data. Enter a '0' if you do not wish to use a mask.]

.BACKGROUND CORRECTION: 2.
[Enter a value to be used instead of the average of each image.]

.SEQUEN FILE: SEQ001
[Enter the name of the sequential file.]

NOTES

  1. This version of 'CA' is rather impractical since it does not allow application of a mask closely following the boundary of the particle. For routine applications, use option 'CA E' ("E" stands for External mask).

  2. Not Distributed!
