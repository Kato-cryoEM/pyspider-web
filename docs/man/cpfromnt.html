CP FROM NT - CoPy NT SPIDER file TO native SPIDER format

(6/26/01)

PURPOSE

Copies a non-native byte ordered SPIDER file into a native byte ordered SPIDER file.

USAGE

.OPERATION: CP FROM NT

.SPIDER INPUT: JNKNT
[Enter the non native byte ordered SPIDER file you want to copy.]

.OUTPUT FILE: JNK000
[Enter the output file.]

NOTES

  1. Does not work on stacks.

  2. Can also convert Compaq Alpha files to SGI files.

  3. NT and Compaq Alpha Unix files have different native byte order from SGI, SUN or IBM Unix files.
