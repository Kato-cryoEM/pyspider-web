CP P - CoPy 'Pologe' format

(7/1/85)

PURPOSE

Copies a SPIDER disk file into a sequential, formatted disk file for outside use. (Created for L. Pologe, Columbia University).

USAGE

.OPERATION: CP P

.INPUT1 FILE: WIN018
[Enter name of file to be copied.]

.OUTPUT FILE NAME: OUT001.DAT
[Enter a 10-character name, including extension, for the sequential output file.]

NOTES

  1. Each image row will be written in the format 20F6.3. Note that, for the VAX at Columbia, a tape density of 800 bpi must be used in the subsequent copying of the sequential file to tape.
