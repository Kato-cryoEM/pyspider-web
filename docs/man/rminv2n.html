RM INV2N - Radon Transform - Computes inverse (Fourier-)Radon transform

PURPOSE

Computes the inverse (Fourier-)Radon transform.

SEE ALSO

RM 3DN [Radon Transform - 3D]
RM COMPLN [Radon Transform - 2D, Complete]
RM FTN [Radon Transform - Fourier transform]

USAGE

.OPERATION: RM INV2N

.INPUT FILE: FRAD001
[Enter name of real space Radon transform.]

.IS THIS A FOURIER TRANSFORM (Y/N)?: Y
[If the input file is a Fourier transformed Radon transform answer Y. Currently there is no information in the file header of Radon transforms that identify if it is in real or Fourier space.]

.OUTPUT FILE: RECON001
[Enter name of output file.]

.X,Y DIMENSIONS: 64,64
[Enter ther dimensions of the backtransformed image.]

.OBJECT DIAMETER: 50
[Enter the diameter of the object in the output image. If this is not known, use the longer of the image dimensions.]

WEIGHTING FUNCTIONS AVAILABLE: CONSTANT (C), CONSTANT WITH 0 AVERAGE (Z), SQRT(R*) (S), R* (R)
.SPECIFY WEIGHTING FUNCTION: R
[Enter choice of weighting function]

.WEIGHTING FUNCTION DOC-FILE: WDOC001
[Enter the name for a document file that will contain the weighting function. This can be used e.g. to produce a plot of this function. It will be well behaved up to the resolution limit defined by Bracewell's/Crowther's formula: N=pi*D/r.]

.INCLUDE LOW-PASS FILTER (Y/N)?: Y
[If Y is answered a fermi low-pass filter will be applied to the weighting function. The radius of this filter is calculated from Crowther's formula.]

.FILTERED RADON FILE: *
