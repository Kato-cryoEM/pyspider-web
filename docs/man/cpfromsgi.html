CP FROM SGI - CoPy SGI SPIDER file TO NT SPIDER format file

(6/26/01)

PURPOSE

Copies a SGI byte ordered SPIDER file into a non-native byte ordered NT SPIDER file.

USAGE

.OPERATION: CP FROM SGI

.INPUT: JNKSGI
[Enter the SGI SPIDER format file you want to copy]

.OUTPUT FILE: JNKNT
[Enter the output file for non-native byte ordering.]

NOTES

  1. Does not work on stacks.

  2. Also used for converting SGI files to Compaq Alpha DEC Unix files.

  3. NT and Compaq Alpha files have different native byte order from SGI, SUN, or IBM Unix files.
