PJ INTER - ProJected Surface - INTERlace two surface representations

(04/22/97)

PURPOSE

Creates an image for red-green stereo representation of surfaces

SEE ALSO

PJ SHAD []
PJ ST [ProJected Surface - Creation]
PJ COL [ProJected surface - COLoring]

USAGE

.OPERATION: PJ INTER

.LEFT EYE IMAGE FILE: LEFT001
[Enter the file containing the surface for the left eye]

.RIGHT EYE IMAGE FILE: RIGHT001
[Enter the file containing the surface for the right eye]

.OUTPUT FILE: STEREO001
[Enter the output file name for the stereo image.]

NOTES

  1. The program normalizes each of the two images and stores one image in the range from 0 to 1 in every second line of the output image, and the second image in the range from 1 to 2 in the alternating lines. If such an image is displayed with a color table that is red in the range from 0 to 1 and green from 1 to 2, then the image can be viewed with red-green stereo glasses. (The left and right sides given above might be inverted, depending on the color table used.)
