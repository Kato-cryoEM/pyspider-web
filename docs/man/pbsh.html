PDB SH - PDB - Shift PDB file

(9/16/06)

PURPOSE

Shift PDB file.

USAGE

.OPERATION: PDB SH

.INPUT FILE: abc.pdb
[Enter the name of the PDB file to be shifted with extension.]

.OUTPUT FILE: def.pdb
[Enter the name of the output PDB file with extension.]

.SXT,SYT, SZT: 100, 200, 300

[Enter X, Y, Z shift (Angstrom)in SPIDER coordinates. If the shift is in unit of pixel, multiply it by pixel size]

NOTES

  1. The program changes the shift into PDB format, and then puts the shift operation to PDB coordinates: a. Change the coordinates system
    SX= SYT
    SY= SXT
    SZ=-SZT
    b. Puts shift operation to PDB coordinates X=XO+SX
    Y=YO+SY
    Z=ZO+SZ

  2. The operation does not change the format of PDB file.

  3. Implemented by Zhong Huang, Pawel A. Penzcek.

SUBROUTINES

PDBSH

CALLER

PDB
