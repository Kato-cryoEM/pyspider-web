CA E - Correspondence Analysis - prepare sequential file

PURPOSE

Create a sequential unformatted file representing a series of aligned images in transposed form, to be used as input to CORAN. This option allows the use of an external mask to transfer only the relevant part of the image information. Has background correction. 'CA ES' is same but has no background correction.

USAGE

.OPERATION: CA E

FIRST FILE: SER001 [Enter the name of the first file in the series.]

.LAST FILE: SER050
[Enter the name of the last file in the series.]

.MASK FILE: MSK001
[Enter the name of the file containing the mask to be applied to the input data. The file must have the same dimensions as the input files.]

.ENTER OFFSET: 4
[Enter the number of files already contained in the sequential file if you want to append or partially overwrite an existing sequential file. Enter '0' if this is a fresh file.]

.BACKGROUND CORRECTION: 2.
[Enter a value to be used to replace the average of each image.]

.SEQUEN FILE: SEQ001
[Enter the name of the sequential file.]

NOTES

  1. If the 'S' option is used, no background correction will be applied. Value entered for background correction will be ignored.

  2. At present, the maximum number of images is 400, and the maximum image dimensions are 99x99.

  3. Not Distributed!
