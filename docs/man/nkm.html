NK M - Shrink to mask

(10/23/96)

PURPOSE

Isolate particle within image frame using threshold criterion. Threshold is placed outside the particle. The picture elements within the particle will be filled with the value 1., and those outside with the value 0, to create a binary mask.

SEE ALSO

NK [Shrink to threshold]
SE [Seed fill an image]

USAGE

.OPERATION: NK M

.INPUT FILE: PIC001
[Enter the name of the input file.]

.OUTPUT FILE: IMG040
[Enter the name of the output file.]

.RETAIN VALUES (A)BOVE OR (B)ELOW THRESHOLD: A

.THRESHOLD: 1.25
[Enter density threshold marking particle boundary.]
