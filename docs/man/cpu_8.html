CP U-8 - CoPy to an 8 bit raw image, unnormalized

(12/28/93)

PURPOSE

Copies a VAX Spider file to an unnormalized 8 bit raw Unix Spider file.

SEE ALSO

CP [CoPy]

USAGE

.OPERATION: CP U-8 (COPY VAX SPIDER FILE TO 8 BIT RAW IMAGE UNNORMALIZED)

.INPUT FILE: PIC001
[Enter the name of the picture to be copied.]

.UNIX FILE: COP001
[Enter the file that will contain the copy.]

.PAD TO INCREMENT OF 4 IF NECESSARY? (Y/N) y
[Will make each line have a value of nsam that is evenly divisible by four. Some devices (such as the Pixar) prefer this.]

SUBROUTINES

COPYU, GETVAX, GETV16, VAX32, , UNIXTOUNIX8, , amp, VAXTOUNIX, ON, UNIX

CALLER

UTIL2
