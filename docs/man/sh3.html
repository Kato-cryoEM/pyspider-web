SH 3 - SHift 3-D

(02/22/96)

PURPOSE

Shifts a volume circularly by a specified 3-D vector (integer or real).

SEE ALSO

SH [SHift - using bilinear interpolation ||]
SH BL [SHift -- using bilinear interpolation]

USAGE

.OPERATION: SH 3

.INPUT1 FILE: PIC001
[Enter the name of the 3-D file containing the volume to be shifted.]

.OUTPUT FILE: PIC002
[Enter the name of the file where the shifted volume is to be stored.]

.SHIFT COMPONENTS (X AND Y DIRECTION): 5,6
[Enter the x and y shift components.]

.SHIFT COMPONENT (Z DIRECTION): 8
[Enter the z component of the shift vector.]

NOTES

  1. The shift is circular; i.e. the image is repeated in all directions.

SUBROUTINES

SHIFT3, SHIFT_3D

CALLER

UTIL2
