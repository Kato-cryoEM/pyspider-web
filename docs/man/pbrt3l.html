PDB RT3L - PDB - Rotate PDB file around line

(9/16/06)

PURPOSE

Rotate PDB file around a line defined by two given points in 3D space.

USAGE

.OPERATION: PDB RT3L

.INPUT FILE: input.pdb
[Enter the name of the PDB file to be rotated with extension.]

.OUTPUT FILE: output.pdb
[Enter the name of the output PDB file with extension.]

.PHI: 100
[Enter rotation angles in degrees.]

.X1, Y1, Z1: 100, 200, 300

[Enter the first given point (Angstrom) in SPIDER coordinate system.]

.X2, Y2, Z2: 20, 30, 40
[Enter the second given point (Angstrom) in SPIDER coordinate system.]

NOTES

  1. The operation does not change the format of the PDB file.

  2. Implemented by Zhong Huang, Pawel A. Penzcek.
