SD S - Sort Document file according to one column

(3/22/96)

PURPOSE

Sorts a document according a chosen column

SEE ALSO

SD [Save Document]
SD C [Save Document - from CA S (_IMC) file]
SD SHUFFLE [Shuffle Document file]

USAGE

.OPERATION: SD S

.SOURCE DOCUMENT: DOC001
[Enter name of input document file]

.FIRST, LAST KEY NUMBER: 1,124
[enter first and last key you want to use]

.COLUMN # USED FOR SORTING: 3
[Enter column number according to which the file will be sorted]

The output docfile will have the format:
NEWKEY, 4, OLDKEY, COLUMN USED FOR SORTING, COLUMN2, COLUMN3

.INPUT COLUMN # FOR COL.2, COL.3: 4, 5
[Enter the column numbers of the values that will be kept in column2 and column3 of the output document file]

.DOCUMENT FILE: DOC002
[Enter name of output document file]

SUBROUTINES

SORTDOC, UNSDAL, SORTZ, OPENDOC

CALLER

DRIV3
