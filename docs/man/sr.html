SR - Save/unsave Registers

(4/22/97)

PURPOSE

Allows the user to save or unsave the values of the registers during a session. (For saving register values permanently to a document file, use 'SD').

SEE ALSO

SD [Save Document]

USAGE

.OPERATION: SR

.(S)AVE OR (U)NSAVE: S
[Registers X0-X99 will then be saved.]

[This operation is useful if it is desired to change the values of the registers, during a SPIDER session, without losing the old values. For example]:

X12=5
SR

.(S)AVE OR (U)NSAVE: S

X12=6

.


.


.

SR

.(S)AVE OR (U)NSAVE: U

[X12 will now contain the value 5.]
