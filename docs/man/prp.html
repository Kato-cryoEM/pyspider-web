PR P - overPRint Power spectrum - to results file

(8/26/96)

PURPOSE

Displays a picture, using overprinting on the line printer. The F(0,0) term of the power spectrum is suppressed in the display.

SEE ALSO

PR T [overPRint image - to Terminal]

USAGE

.OPERATION: PR P

.INPUT FILE: PIC001
[Enter the name of the file of interest.]

.CONTOURING?(Y/N): Y
[Enter whether or not contouring is desired.]

If 'Y' is answered, the following question appears:

.NUMBER OF LEVELS: 5
[Enter number of contour levels.]

[The file will then be printed (with overprinting) to the results file, with 5 levels of contouring. If contouring is not desired, then an 'N' should be entered. Note that as in all SPIDER contouring programs (e.g. 'FC'), the levels of maximum and minimum OD are counted as contour levels. In the above example, only three contours would be visible, plus the two points where the maximum and minimum of the image are assumed.]
