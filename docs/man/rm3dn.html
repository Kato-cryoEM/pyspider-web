RM 3DN - Radon Transform - 3D

PURPOSE

Computes the Radon transform of a three-dimensional image, (New format)

SEE ALSO

RM 3DN [Radon Transform - 3D]
RM COMPLN [Radon Transform - 2D, Complete]
RM FTN [Radon Transform - Fourier transform]
RM FTINVN [Radon Transform - Inverse Fourier transform]
RM INV2N [Radon Transform - Computes inverse (Fourier-)Radon transform]
RM INV3N [Radon Transform - Computes inverse 3D (Fourier-)Radon transform]

USAGE

.OPERATION: RM 3DN

.THREED FILE: VOLUME001
[Enter name of three-dimensional volume]

.3D THRESHOLD/LIFT/NONE (T/L/N): N
[Enter if you wish to (T)hreshold the volume in 3D, (L)ift the minimum up to 0 or (N)one of the above.]

If "T" was answered:
.UPPER,LOWER THRESHOLD:1.1,-0.2
[enter upper and lower threshold]

.AVERAGE 2D THRESHOLD (Y/N): N
[Enter Y if you want to have the intermodiate 2D projections thresholded below their average.]

.RADON TRANSF. SAMPLE DIM.: 64
[Enter line dimension of Radon transform.]

.OUTPUT FILE: THREEDRAD001
[Enter name of output file.]

.ANGULAR INCREMENT THETA,PHI: 10,5
[Enter the angular sampling for the Radon transform. Theta angle around y, phi angle within the intermediate 2D projections.]

.RADIUS OF SPHERICAL MASK: 30
[The volume is masked by a sphere with this radius before the Radon transform is calculated.]

.WRITE INTERMEDIATE PROJECTIONS (Y/N): N
[Allows to write the intermediat 2D projections (a single axis tilt series).]

If "y" was answered:
.OUTPUT FILE: INTERPRO001
[Enter file name template for an output file series. These files will be numbered sequentially, starting with 1.]
